# 空之轨迹 the 3rd · Steam 版日文还原补丁

**Sora3rd JP Restore** — 一键把 Steam 英文版《The Legend of Heroes: Trails in the Sky the 3rd》转换为日文原版体验（剧本 / 系统文本 / 原版字体），并可一键还原。

本工具是纯粹的**补丁器**：不包含任何游戏数据，转换素材全部来自使用者本机合法拥有的两份游戏。

---

## 项目起源

一切始于一块 32:9 的超宽屏。

Steam 英文版在 >21:9 的分辨率下 UI 直接散架——标题漂移、元素飞出屏幕。为了让它在 32:9 上能玩，先做了 16:9 窗口化居中的"伪全屏"方案。然后发现了更要命的事：**这个版本没有日文**。

准确地说，不是没有日文的"能力"：XSEED 移植版用的就是 Falcom 原版引擎，exe 里完整保留着日文的菜单和系统字符串——在游戏目录 `dll\` 下放一个空的 `lang_jpn.dll` 文件，菜单和设置界面立刻变日文。但 XSEED 在打包时把**日文剧本从数据文件里删掉了**（FC/SC 两代保留了双语文本，唯独 the 3rd 没有），所以剧情对话永远只能是英文。社区对此的结论是：想玩日文 3rd，只能去买日本原版。

而日文原版从不上 Steam（全球任何区都没有），只挂在 DLsite / DMM 上卖 2007 年的老版本——没有 XSEED 版的 DX9、高清素材、加速模式和宽屏适配。在 7680x2160 的屏幕上，那是一个全面降级。

于是就有了这个项目：**买下 DLsite 日文版（VJ009177），逆向 Falcom 的 LB DIR/DAT 封包格式，把日文内容灌回英文版引擎，让 Steam 版直接变成日文版。**

过程中的几个关键发现，也是本工具存在的理由：

- 英文版引擎有 **7 个 XSEED 自己新增、日版封包里没有的文件**。直接整包替换会启动闪退——其中 `T_BTREV`（战斗语音表）是引擎启动必读项。所以这 7 个文件必须单独**回填**进日版封包的占位槽（`/_______.___`）。
- **字体是最后一环**。XSEED 的高清字库（FONT8–FONT256 共 25 档）与日版的字间距/基线度量不同，用它显示日文剧本会出现人名和正文的排版漂移。换入日版原点位图字体（FONT8–FONT32）并启用经典渲染（`HighResoText=0`）后，排版回到原版状态。
- 日版与英文版的多数封包字节级一致（贴图、音频），真正需要动的只有三个档案：`ED6_DT21`（全部地图剧本）、`ED6_DT22`（系统文本库）、`ED6_DT20`（字体）。

换句话说：为了不在 32:9 上玩散架的英文版，最后把两个版本的游戏都逆向了一遍。

## 功能

| 项目 | 内容 |
|---|---|
| 剧情文本 | `ED6_DT21` 全部地图剧本 → 日版（回填英文版独有 5 文件） |
| 系统文本 | `ED6_DT22` 物品/魔法/任务/书物/钓鱼/料理等 → 日版（回填 `T_BTREV`、`T_QUIZ04`） |
| 字体 | `ED6_DT20` 中 FONT8–FONT32 → 日版原点位图字体 |
| 菜单 | 写入 `dll\lang_jpn.dll`，系统菜单/设置界面日文 |
| 渲染 | `ed6_win3.ini` 设 `HighResoText=0`，经典字体渲染，修复排版漂移 |
| 还原 | 任意时刻一键还原英文原版（转换前自动备份） |

转换后：剧情对话、物品/技能/任务文本、系统菜单全部为日文；引擎特性（DX9、加速模式、手柄、云存档）全部保留。

## 使用方法

**一键：** 关闭游戏 → 双击 `一键转换.bat` → 按提示输入日文版路径 → 完成。

**命令行：**

```powershell
# 转换
powershell -File Convert-Sora3JP.ps1 -JpSource "D:\path\to\ED_SORA3 或 VJ009177.zip" `
         [-GameDir "英文版目录，缺省自动探测"] [-KeepHdFont]

# 还原（默认使用最近一次备份）
powershell -File Convert-Sora3JP.ps1 -Restore [-BackupDir "指定备份目录"]
```

- `-KeepHdFont`：保留 XSEED 高清字体，不换日版原点位图字体（也不改 `HighResoText`）。
- 每次转换都会在 `backup\` 下按时间戳新建一份英文原版备份，绝不覆盖旧备份。
- Steam "验证游戏完整性"或游戏更新会把封包还原为英文 → 重新运行一次一键转换即可。

## 已知限制

- **贴图类内容仍为英文**：标题 LOGO、标题/难度按钮、开场旁白卡、结局 STAFF 表等（这些是预渲染图片，不是文本；替换需改 HD 贴图包，不在本项目范围）。
- 32:9 等 >21:9 分辨率下的 UI 布局异常是引擎自身问题，与本补丁无关；可用 `extras/16x9-pillarbox/` 里的伪全屏小工具解决（16:9 窗口化 + 无边框居中，超宽屏两侧留黑）。
- 存档与语言无关，转换前后通用。

## 技术细节

- 封包格式：`LB DIR` / `LB DAT`，16 字节头（magic + 条目数）。`.dir` 每条目 36 字节（12 字节 8.3 名称 + 4 字节填充 + 5 个 DWORD：尺寸/标志/缓冲尺寸/哈希/偏移）。`.dat` 为偏移表 + 数据块；**末位哨兵偏移恒为 0**（格式特性，末条目长度需按文件总长计算）。
- 日版档案内文件按 16KB 块对齐存储，英文版为紧凑存储；引擎按条目内偏移/尺寸读取，两种布局均兼容。
- 英文版独有文件回填至日版档案的空槽（条目名 `/_______.___`），条目记录（含哈希）随内容原样保留。
- 工具链：PowerShell 5.1 + 内嵌 C#（`Add-Type` 运行时编译），零外部依赖。
