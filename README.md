# 空之轨迹 the 3rd · Steam 版日文还原补丁

**Sora3rd JP Restore** — 一键把 Steam 英文版《The Legend of Heroes: Trails in the Sky the 3rd》转换为日文原版体验：剧本 / 系统文本 / 原版字体 / 预渲染素材（标题、卡片、角色立绘、结尾 STAFF 表），并可一键还原。

本工具是纯粹的**补丁器**：不包含任何游戏数据，转换素材全部来自使用者本机合法拥有的两份游戏。

---

## 项目起源

一切始于一块 32:9 的超宽屏。

Steam 英文版在 >21:9 的分辨率下 UI 直接散架——标题漂移、元素飞出屏幕。为了让它在 32:9 上能玩，先做了 16:9 窗口化居中的"伪全屏"方案。然后发现了更要命的事：**这个版本没有日文**。

准确地说，不是没有日文的"能力"：XSEED 移植版用的就是 Falcom 原版引擎，exe 里完整保留着日文的菜单和系统字符串——在游戏目录 `dll\` 下放一个空的 `lang_jpn.dll` 文件，菜单和设置界面立刻变日文。但 XSEED 在打包时把**日文剧本从数据文件里删掉了**（FC/SC 两代保留了双语文本，唯独 the 3rd 没有），所以剧情对话永远只能是英文。社区对此的结论是：想玩日文 3rd，只能去买日本原版。

而日文原版从不上 Steam（全球任何区都没有），只挂在 DLsite / DMM 上卖 2007 年的老版本——没有 XSEED 版的 DX9、高清素材、加速模式和宽屏适配。在 7680x2160 的屏幕上，那是一个全面降级。

于是就有了这个项目：**买下 DLsite 日文版（VJ009177），逆向 Falcom 的封包与压缩格式，把日文内容灌回英文版引擎，让 Steam 版直接变成日文版。**

过程中的几个关键发现，也是本工具存在的理由：

- 英文版引擎有 **7 个 XSEED 自己新增、日版封包里没有的文件**。直接整包替换会启动闪退——其中 `T_BTREV`（战斗语音表）是引擎启动必读项。所以这 7 个文件必须单独**回填**进日版封包的占位槽（`/_______.___`）。
- **字体**：XSEED 的高清字库（FONT8–FONT256 共 25 档）与日版的字间距/基线度量不同，直接显示日文剧本会人名和正文排版漂移。换入日版原点位图字体（FONT8–FONT32）并启用经典渲染（`HighResoText=0`）后，排版回到原版状态。
- **16 位色之毒**：日版部分 UI 素材是 ARGB1555（16 位色）贴图，英文版 DX9 引擎**拒绝渲染**——标题/难度按钮会凭空消失（"被吞了")。本工具内置 bzip 解压 + 像素转换 + 重打包管线，把受影响的 22 张角色立绘转成 32 位色，问题根除。
- **意外之喜**：`ED6_DT51` 不是别的，是**结尾 STAFF 表影像**——日版是 MPEG 原片，内含 Evolution 版全声优表（英文版是 XSEED 重渲的 AVI)。本工具可将其转码为 XviD AVI 一并换入（`-StaffRoll`）。
- 日版与英文版的多数封包字节级一致（贴图、音频），真正需要动的只有几个档案。

换句话说：为了不在 32:9 上玩散架的英文版，最后把两个版本的游戏都逆向了一遍。

## 功能

| 项目 | 内容 |
|---|---|
| 剧情文本 | `ED6_DT21` 全部地图剧本 → 日版（回填英文版独有 5 文件） |
| 系统文本 | `ED6_DT22` 物品/魔法/任务/书物/钓鱼/料理等 → 日版（回填 `T_BTREV`、`T_QUIZ04`） |
| 字体 | `ED6_DT20` 中 FONT8–FONT32 → 日版原点位图字体 |
| 界面素材 | `C_SUBTI`（副标题 logo）、`C_STATUS`、`C_ICON1`、`C_NOTE1` → 日版 |
| 角色立绘 | `C_STCH00`–`C_STCH36` 共 22 张入队立绘 → 日版（ARGB1555 转 32bpp，修复 16 位色不渲染） |
| 卡片素材 | `ED6_DT24` 全部 `C_*`（标题界面、剧情卡、地名卡、门标题卡、笔记本等）→ 日版 |
| 结尾 STAFF 表 | `ED6_DT51` → 日版原片（含 Evolution 声优表；`-StaffRoll` 开启，有 ffmpeg 时自动转码为可播放的 XviD AVI） |
| 菜单 | 写入 `dll\lang_jpn.dll`，系统菜单/设置界面日文 |
| 渲染 | `HighResoText=0`（经典字体渲染，修复排版漂移）、`HighResoAssets=0`（使用日版标准素材） |
| 还原 | 任意时刻一键还原英文原版（转换前自动备份） |

转换后：剧情对话、物品/技能/任务文本、系统菜单、标题画面、入队立绘、各类卡片、结尾 STAFF 表全部为日文；引擎特性（DX9、加速模式、手柄、云存档）全部保留。

## 使用方法

**一键：** 关闭游戏 → 双击 `一键转换.bat` → 按提示输入日文版路径 → 完成。

**命令行：**

```powershell
# 转换（全部功能）
powershell -File Convert-Sora3JP.ps1 -JpSource "D:\path\to\ED_SORA3 或 VJ009177.zip" `
         [-GameDir "英文版目录，缺省自动探测"] [-KeepHdFont] [-NoTextures] [-StaffRoll]

# 还原（默认使用最近一次备份）
powershell -File Convert-Sora3JP.ps1 -Restore [-BackupDir "指定备份目录"]
```

- `-KeepHdFont`：保留 XSEED 高清字体，不换日版原点位图字体（也不改 `HighResoText`）。
- `-NoTextures`：只换剧本/文本库/字体，跳过全部预渲染素材。
- `-StaffRoll`：同时替换结尾 STAFF 表影像为日版原片。
- 每次转换都会在 `backup\` 下按时间戳新建一份英文原版备份，绝不覆盖旧备份。
- Steam "验证游戏完整性"或游戏更新会把封包还原为英文 → 重新运行一次一键转换即可。

## 已知限制与说明

- **序章开场旁白卡仍为英文**（"That brief hesitation..."、"Year 1203..." 一组）：这是 XSEED 自行烘焙的私有内容，不属于游戏剧本体系，日版没有可替换的对等文件（日版的这段叙事由引擎文本直接渲染）。目前唯一保留的英文文本，仅在开机/开新档时出现十几秒。
- **以下英文属日版原版设计，并非遗漏**：标题的 START/LOAD/OPTION/EXIT、难度的 EASY/NORMAL/HARD/NIGHTMARE、"Now Loading..."。已用日版原版实机验证——这些按钮在日版中即为英文（且 2007 年原版没有难度选择界面）。
- 结尾 STAFF 表转码需要 ffmpeg；未提供时直接拷入日版 MPEG 原片，若系统缺少 MPEG-PS 解码器（Win8+ 不再自带）可能无法播放，安装 LAV Filters 或重跑 `-StaffRoll` 即可。
- 32:9 等 >21:9 分辨率下的 UI 布局异常是引擎自身问题，与本补丁无关；可用 `extras/16x9-pillarbox/` 里的伪全屏小工具解决（16:9 窗口化 + 无边框居中，超宽屏两侧留黑）。
- 存档与语言无关，转换前后通用。

## 技术细节

- **封包格式**：`LB DIR` / `LB DAT`，16 字节头（magic + 条目数）。`.dir` 每条目 36 字节（12 字节 8.3 名称 + 4 字节填充 + 5 个 DWORD：尺寸/标志/缓冲尺寸/哈希/偏移）。`.dat` 为偏移表 + 数据块；**末位哨兵偏移恒为 0**（格式特性，末条目长度需按文件总长计算）。
- **存储布局**：日版档案内文件按 16KB 块对齐存储，英文版为紧凑存储；引擎按条目内偏移/尺寸读取，两种布局均兼容。
- **压缩**：Falcom 私有 bzip（mode1 字节级 / mode2 位级 LZSS）+ ed6 分块容器（u16 块长 + 续块标志）。本工具内置完整解压器与合法重打包器（mode1 纯字面量编码）。
- **像素格式**：dir 条目标志位区分格式类（如 0x10000=8bpp、0x20000=ARGB1555、0x80000=32bpp 等）。英文版 DX9 引擎拒绝渲染 16 位色（0x20000 类），故 `C_STCH` 立绘需转换像素格式；其余素材日英格式类一致，直接换内容即可。
- **回填机制**：英文版独有文件回填至日版档案的空槽（条目名 `/_______.___`），条目记录（含哈希）随内容原样保留。
- **标题图集（C_TITLE1）合成**：日英两版的标题图集布局不同——日版顶部为空轨 logo、英文版为 Trails logo 且含 START/EASY 按钮格（这些按钮文字在日版原版中即为英文，属原版设计）。整包替换会让难度按钮丢失，故采用合成：取日版图集顶部 185 行（空轨 logo 原生大小）+ 英文版底部按钮/装饰区，得到"日文 logo + 原版英文按钮"的原版构图。
- **工具链**：PowerShell 5.1 + 内嵌 C#（`Add-Type` 运行时编译），零外部依赖；ffmpeg 仅 `-StaffRoll` 可选使用。
